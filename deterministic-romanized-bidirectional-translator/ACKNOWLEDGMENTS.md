# Acknowledgments

This project builds a deterministic Nepali Devanagari <-> romanized transliterator.

It was informed by and tested against behavior from:

- [`isDipesh/nepali-romanization`](https://github.com/isDipesh/nepali-romanization), a Python Devanagari-to-romanized Nepali project. We use small example cases and behavior as comparison fixtures. This repository does not vendor or redistribute its source code.
- [`BipinBudhathoki01/Nepaile-Unicode`](https://github.com/BipinBudhathoki01/Nepaile-Unicode), an MIT-licensed Romanized Nepali <-> Nepali Unicode converter. We use small example cases and behavior as comparison fixtures. This repository does not require its JavaScript runtime code.

The default translator in this package is pure Python and self-contained.
